# WANTED.git

## Western-Style Competitive Coding Platform (Solo + Duels)

`wanted.git` is a competitive coding arena inspired by LeetCode-style challenges, enhanced with western cowboy aesthetics, XP, ranks, badges, and real-time duels.

### Key Features
- **Solo Mode**: Timed coding challenges for practice and rank progression.
- **Duel Mode (1v1 Showdown)**: Real-time matchmaking and parallel coding challenges.
- **Fair Play**: Identical problems, execution environments, and anti-cheat measures.
- **Scoring**: Balanced formula (60% Correctness, 25% Efficiency, 15% Speed).
- **Gamification**: XP system, ranks (Rookie to Legend), and performance-based badges.

### Project Structure
- **/Backend**: Node.js/Express server handling authentication, judging, and matchmaking.
- **/frontend**: Next.js/React application with a western-style UI and Monaco Editor integration.
- **/Docs**: Additional documentation and project assets.

### Technology Stack
- **Frontend**: Next.js, TypeScript, Tailwind CSS, Monaco Editor.
- **Backend**: Node.js, Express, PostgreSQL, Redis, Docker (Judging Sandbox).
- **Communication**: WebSockets for real-time duel state.
